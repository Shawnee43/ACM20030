Assignments 1-5 were part of a computational science module which I took in second year. In assignment 1, various root finding algorithms are studied along with their rate of convergence. We investigate real world data using a linear least squares algorithm in assignment 2. In assignment 3 and 4, we learn about certain differential equations and integrals that have no analytical solution. These notebooks contain various algorithms such as the Runge Kutta and Trapezoidal method to solve these types of equations. Finally in assignment 5 we use code to explore the various types of norms of a matrix along with other linear algebra topics.
